# P2 — daily HTTP, authentication and secrets

P2 covers the supported local HTTP/auth subset. The task-level acceptance result and command evidence are in [P2_ACCEPTANCE.json](verification/P2_ACCEPTANCE.json); [the tracker](TASK_TRACKER.md) remains the source of task counts and the next phase. This phase does not certify a stable cross-platform release.

Credentials use origin-bound UUID references, explicit session storage or an available native OS vault, and separate credential purposes. The macOS native check exercised create/read, metadata privacy, refusal of an unapproved destination, independent-process restart and deletion. Migration reviews list paths without values, recheck revisions, and require storage/recovery consent. CLI snapshots/backups and Postman exports redact structured secrets by default; raw inline export requires explicit consent. Lossless migration/restore recovery backups require plaintext consent when inline credential candidates exist. Existing historical copies are retained for recovery.

OAuth uses pinned oauth4webapi for authorization code with PKCE, state, owned loopback callbacks, OIDC nonce/signature validation, client credentials, bounded token requests, expiry, single-flight refresh, atomic refresh rotation and explicit local clear/provider revoke. A real browser test exercised provider navigation through the fixed callback, callback replay refusal, connection selection, approved-origin execution and revocation. The callback navigation exception does not open other management APIs to foreign sites.

HTTP/1.1 execution preserves ordered repeated fields and exact chosen-file bytes. Binary/multipart uploads use private session capabilities; imported paths never grant file access. Cookie editing, domain/path/secure matching, explicit native persistence, clear/forget controls, serialized writes and stalled-provider handling are exercised. HTTPS verification remains enabled; custom CA and mTLS fixtures prove rejection without the selected certificate/key and success with them. Response streaming supplies progress, a bounded preview, and an exact complete download artifact. Cancellation and decoded byte budgets cover uploads, headers, compressed bodies, observers and incomplete artifacts.

The Studio exposes sensitive credential inputs, migration review, OAuth management, cookie/TLS controls, file selection, schema validation and response inspection. Collection/folder authorization uses the same typed controls and preserves unsupported imported metadata until explicitly replaced. JSON validation uses pinned Ajv in bounded disposable workers. Raw script state remains in a private execution channel for chaining; published maps, logs, assertions, examples and reports are redacted. Script mutations containing a known secret are refused for automatic plaintext persistence. Direct, redirected and script-child requests cannot target Studio's control origin.

Verification artifacts distinguish actual local HTTP/TLS/provider/native integration from supplemental browser network doubles. P1 ownership/conflict regression and authoring checks were rerun. The package check installs a fresh production-only tarball and executes its CLI/interpreter; the VS Code extension build is also checked. No commit, deployment, live workspace migration or third-party account authorization is part of this phase.

Remaining platform/release work belongs to P5: Linux Secret Service integration is unverified, Windows persistent credential metadata needs private ACL support (session storage works; persistent creation fails explicitly), and installed extension-host/cross-platform certification remains open. The implementation cannot identify arbitrary unknown secrets or cryptographic transformations in free text/scripts; review exports and configure sensitive fields. HTTP/2 and additional protocols/auth schemes remain outside the supported P2 subset. Native writes cannot be forcibly cancelled: an exceeded cookie-storage wait reports an uncertain outcome, blocks blind retry while pending, and shutdown retains the writer lease until native work settles.
